**CampusConnect - Campus Event Management Portal
Introduction**
CampusConnect is a web-based Event Management Portal designed to simplify the process of managing and participating in campus events. The platform provides a centralized environment where students can discover upcoming events, view event details, register online, save preferred events, and manage their participation efficiently.

The application eliminates the limitations of traditional event management methods by providing a digital solution that improves communication between event organizers and students while reducing administrative effort.

**Project Objectives**
To provide a centralized platform for campus events.
To simplify event registration and participation.
To improve accessibility of event information.
To reduce paperwork and manual record management.
To encourage student engagement in academic and extracurricular activities.
To demonstrate the implementation of modern web development technologies.
